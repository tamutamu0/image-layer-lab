# 構成と検証

## 主要ファイル

| 場所 | 役割 |
| --- | --- |
| `src/app-server.mjs` | 共有app-server接続、独立スレッド、通知の振り分け |
| `src/pipeline.mjs` | モデルの確認・呼び出し・実測記録。分析専用指示と画像生成指示を分離 |
| `src/separation/options.mjs`, `routing.mjs` | 工程別モデル・推論設定・再確認・並列数 |
| `plan.mjs`, `compact-plan.mjs` | AIの構造判断を短いJSONにし、共通の抽出指示を補完 |
| `source-copy.mjs` | 原画像の独立読み取り、計画との照合、数値修正の確認 |
| `core.mjs`, `run.mjs`, `outpaint.mjs` | 生成、依存関係、キャッシュ、枠外補完 |
| `ocr.mjs`, `native.mjs` | 小分けOCR、問題のある項目だけ再確認、編集可能テキスト |
| `register.py`, `trim.mjs` | 位置合わせ、透明余白の調整 |
| `review-compact.mjs`, `run-overlap.mjs` | 全素材の評価、限定的な修正、評価と書き出しの並列実行 |
| `build.mjs`, `speculative-build.mjs`, `src/sketch.mjs` | 階層・Sketch生成・読み戻し・出力ハッシュ |
| `src/evaluate-reasoning.mjs` | 保存済み素材で工程別のモデル比較 |

フォルダを省略したファイルは `src/separation/` 内です。

## 生成と編集単位

編集単位・座標・重なり・隠れた範囲・文字はAIが決めます。共通指示をコードで補うのは出力を短くするためです。レイヤーの切り方を固定テンプレートに置き換える処理ではありません。元画像は参照用の切り抜きを生成モデルに渡しますが、完成素材を原画像から機械的に切り出す方式ではありません。

枠外の内容、元画像で隠れた内容、背景の消された箇所は生成で補完します。独立して動かす必要がある白もや・反射・光彩は効果レイヤーにします。修正できる位置・サイズ・透明度の問題は画像再生成より先に調整します。

## 並列処理と保存

app-serverは共有し、各モデル呼び出しは独立スレッドで行います。画像生成は最大6並列、OCRは素材が揃った小分け単位から開始します。レビューと仮の書き出しの両方が完了するまで、参照素材を変更しません。修正が必要なら仮の出力を破棄します。

Sketchは自己完結したファイルを最後にatomic renameで配置します。補助ファイル群全体の同時更新を保証するものではありません。出力のハッシュを保存します。

## 検証対象

自動テストでは、計画の構造・座標、モデル経路、並列上限、OCRの欠落・数値不一致、キャッシュ、評価の限定的な再確認、原画像の文字と計画の差、ネストした書き出し、Sketchの読み戻しを確認します。分析処理が画像生成を試みた結果を拒否する検査も含みます。これは事後検査であり、サーバー側のツール無効化設定ではありません。

```sh
npm test
```

API呼び出しは行いません。文字・素材のテスト入力は合成したものです。

## 既知の限界

- 計画と独立OCRが同じ見落としをした場合、後の視覚評価でも見落とす可能性があります。
- 再生成によって外観・形状・書体が変わる可能性があります。
- 隠れた部分の正解画像は存在せず、補完の正しさを完全には検証できません。
- 修正回数には上限があり、必ず実用範囲に到達する保証はありません。
- Sketchのスキーマ・画像読み戻しが通っても、FigmaやSketchアプリ側での実表示は別途確認が必要です。
- ネットワーク・認証・制限エラーで、別モデルへ勝手に変更しません。

公開リポジトリの履歴はこの汎用パッケージから開始します。個別商品や過去の実行結果を取り込むインポート・履歴のコピーは行いません。
